# Big L Driving School Website

This is a professional, mobil-responsive landing page built with HTML and CSS.

## Live Demo
You can view the live website here:
[https://sheerazdev123-glitch.github.io/my-web-project/](https://sheerazdev123-glitch.github.io/my-web-project/)


## Key Features
* **Mobil Resposive**: Custom media queries ensure a great experience on phones
* **Navigation systems**: Sticky Header with smooth-scrolling anchor links.
* **Floating UI**: "Back To Top" button for improved navigation
* **Mordern layout**: Uses flexbox for alignment and a clean, professional "vibe".


## Built with:
* HTML5 
* CSS3 (flexbox & Media Queries)
* Git/GitHub for Version Control.
